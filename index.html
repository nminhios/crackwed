Tại sao bị lỗi?
Browser chặn fetch chéo domain (CORS). Proxy là cầu nối nhưng một số website block luôn proxy → dùng Cách B hoặc Script Python để bypass hoàn toàn.
Mạnh nhất — không bị chặn:
1. Nhập URL bên trái → bấm Bắt Đầu Tải
2. Lệnh tự sinh ra bên dưới → copy
3. Mở Terminal / cmd → dán → chạy

Cần cài wget: winget install GnuWin32.Wget
Bypass mọi thứ thủ công:
1. Mở website mục tiêu → Ctrl+U
2. Ctrl+A → Ctrl+C (copy toàn bộ)
3. Dán vào ô dưới → bấm Phân Tích
