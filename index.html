🧩 Chỉnh sửa trực tiếp bất kỳ vị trí nào trong file

Offset tính từ đầu file và nhập bằng hệ 16 (hex). Chế độ “Thay thế” ghi đè N byte bằng dãy hex mới; “Chèn” thêm byte tại offset; “Xóa” bỏ N byte. Đây là chỉnh sửa nhị phân, không tự sửa cấu trúc nội bộ của định dạng.

Chọn file để bắt đầu.

🧬 Audio Forensics Lab — dò dữ liệu bị ẩn / biến đổi

Quét header audio thô, chữ ký bị XOR 1 byte / đảo bit / đổi nibble, và chuỗi Base64 chứa audio. Nếu dữ liệu dùng AES hoặc thuật toán riêng thì cần khóa/thuật toán gốc; entropy cao chỉ là dấu hiệu dữ liệu nén/mã hóa, không chứng minh đó là âm thanh.

Chọn một file, sau đó quét. Với các phát hiện XOR, bấm “Chọn vùng” để điền offset/khóa tự động.
